What is Jenkins?

Jenkins is an open-source automation server used for CI/CD (Continuous Integration and Continuous Delivery). It watches your code, and every time something changes it automatically builds, tests and deploys the application, so nobody has to repeat those steps by hand.

  • Automates the pipeline: checkout, build, test, package and deploy.
  • Catches problems early: a broken build is found right after a commit.
  • Pipeline as code: the steps can be stored in a Jenkinsfile alongside your project.
  • Plugin ecosystem: Git, Maven, Docker, Kubernetes and Tomcat deployment all plug in.

In this project, Jenkins pulls the code, builds the WAR file with Maven and deploys it to Tomcat under the /javawebapp context.
